# New Year 2027 (Ամանոր 2027)

A New Year ritual website for Armenia and the diaspora: one map of Armenia split into 111,111 places (500×500 m plots, this year only). 20% of every payment goes to New Year gifts for children in Armenian children's homes.

The home page introduces the project. In the **map app** (`/map/`) a buyer takes any free place, decorates its small 3D room (tree, sofa, fireplace, TV and so on; `site/assets/js/room.js`), sets how it looks on the map (icon, colour, message, signature) and pays 600 AMD. Every place includes exactly one wish, written in the map's Fire tab (`/map/#fire`) and burned live on 31 December at `/live/` and on a YouTube stream. Anyone can tap a taken place and step into its room. Papers are no longer sold separately; the old `/fire/` and `/burn/` addresses redirect to `/live/` and `/map/#fire`.

Live at [lightarmenia.com](https://lightarmenia.com). The brand name and domain are set in one place: `site/config/site.json`.

## Layout

| Path | What |
|---|---|
| `site/` | Source of the website: templates, texts (`i18n/`), legal pages (`content/`), styles and scripts (`assets/`), config |
| `site/build.py` | Generates the static site into `public/` |
| `public/` | Generated output that Vercel serves (committed, so no build step runs on Vercel) |
| `supabase/` | Database migrations, server functions (payments, orders), tests |
| `docs/` | Architecture and backend notes |
| `vercel.json` | Hosting config: security headers, redirects, clean URLs |

## Everyday tasks

Rebuild after changing anything in `site/`:

```sh
python3 site/build.py        # needs python3 with jinja2 and markdown
```

Commit both `site/` and `public/`. Pushing to `main` deploys to Vercel.

- **Open payments:** set `"payments_open": true` in `site/config/site.json`, rebuild, and set the `PAYMENT_PROVIDER` function secret in Supabase (see `docs/BACKEND.md`).
- **Company details for the legal pages:** `company` in `site/config/site.json`.
- **Domain:** `domain` and `site_url` in `site/config/site.json`, plus `SITE_URL` and `ALLOWED_ORIGINS` in Supabase function secrets.
- **YouTube stream:** `stream.youtube_embed_id` in the config.
- **Gift partner and reports:** `gifts` in the config.
- **Map plots:** generated by `python3 tools/make_map.py <Natural Earth geojson dir>` into `site/assets/data/map.js` and `supabase/migrations/0004_cells_seed.sql`. Don't regenerate after launch: plot ids must stay the same.
- **Light prices:** `light_products` in the config and the `products` table (migration `0005_lights.sql`).
- **The stream capture page:** open `/live/?stream=1` in OBS (browser source, 1920×1080).

See `docs/ARCHITECTURE.md` for how the parts fit together.
